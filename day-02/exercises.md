

# Day 2: Variables and Built-in Functions

## Resumo do conteúdo do dia
- Variáveis e como declará-las
- Declaração de múltiplas variáveis em uma única linha
- Tipos de dados básicos (`str`, `int`, `float`, `bool`)
- Funções built-in principais: `type()`, `len()`, `input()`
- Conversão de tipos (casting)
- Operações matemáticas básicas (+, -, *, /, %, **, //)
- Cálculos com círculo (área e circunferência)
- Uso de `help('keywords')` para ver palavras reservadas do Python
